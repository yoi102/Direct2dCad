## 目标与顺序

当前按 **Windows 二维工程制图** 规划：用户能准确画图、方便改图、标注尺寸、保存恢复，并把图纸交给别人或按比例打印。已有图层、块、Layout、描边属性和渲染基础继续使用。

| 阶段 | 用户得到的结果 | 主要任务 | 开始条件 |
| --- | --- | --- | --- |
| M1：输入和文件可信 | 输入的点就是实际的点，文件操作不会静默丢内容 | 已复现缺陷、覆盖保护、文件预算、恢复副本和兼容策略 | 业务代码与本机回归完成；现场恢复/打印与实际输入延迟待专项验收 |
| M2：精准绘图且界面清楚 | 看得懂当前步骤，容易捕捉正确点，常用设置直接可达 | 对象捕捉、正交/极轴、画布动态输入、属性与简洁状态栏 | 代码与指定桌面自动化完成；多屏 DPI/输入法人工验收保留 |
| M3：完成常用改图 | 通过预览完成偏移、修剪、延伸等操作 | 几何公差基础、变换覆盖、分批编辑命令 | 直线/圆弧路径编辑等声明范围完成；不宣称任意曲线支持 |
| M4：完成工程标注 | 尺寸随图形更新，样式和比例保持一致 | 关联尺寸、引线、尺寸样式、工程模板 | 七种标注与直接关联、属性、模板完成；专项人工制图验收保留 |
| M5：完成图纸交付 | DXF 可交换，打印尺寸可信 | 分范围 DXF 读写、实际尺寸/指定比例打印 | 有界 DXF 和独立样图验证、PDF 驱动预览完成；实际输出待现场验收 |
| M6：容量与正式分发 | 大图纸可操作，版本可复现，安装升级可靠 | 响应基线、取消、快照、清理/历史预算、发布验收 | 可见优先首屏、分项测量、历史预算和本机包完成；干净机器/签名/公开发布保留 |

阶段表示交付顺序，不要求等待整个上一阶段才开始所有工作。固定 SDK、托管 CI、长操作取消和性能测量从 M1 起推进；每个新增工具都需要当期验证响应和交互，不能把卡顿留到 M6。

## 所有阶段共用的交互规则

| 方面 | 设计约定 | 验收重点 |
| --- | --- | --- |
| 入口 | 常用工具放现有 Ribbon 分组；属性使用现有属性面板；详细选项按需展开。画布、Terminal 和 AI 使用同一操作能力 | 鼠标可以完成常用任务，不要求手写 JSON；不同入口生成一致几何和历史 |
| 当前步骤 | 画布在对应尺寸或光标位置显示小数字框，Tab 切换、Enter 确认、Esc 取消；状态栏悬停显示完整说明 | 不显示大面板、步骤标题和常驻快捷键说明；输入不拦截画布鼠标点选；数字框按内容收缩，状态栏只留简短工具名、坐标/单位和常用开关；提示使用当前语言 |
| 提交与取消 | 先预览再提交；完成一个动作形成明确撤销单位；`Esc` 清理未提交操作；长操作有自己的“取消”入口 | 预览不污染模型、存储或历史；失败不留下半成品；撤销/重做恢复相关几何与依赖 |
| 输入焦点 | 快捷键按画布、属性输入、Terminal 焦点分派；编辑文字时不触发画布命令；操作完成不抢其他文档焦点 | 中文/日文输入法、Tab 导航、数值输入和命令建议不发生双重提交 |
| 属性 | 图层、颜色、线宽、常用线型优先展示；端帽、连接、细分填充参数放可展开区域；适用字段完整保留 | 简洁不能通过遗漏描边设置实现；绘制默认值、实体属性与多选属性的作用对象清楚 |
| 反馈 | 正常保存通过脏标记/短状态反馈，不弹成功对话框；捕捉与预览就地提示；失败给原因和下一步 | 不重复弹窗；恢复、覆盖或有损输出等数据风险在同一操作中集中说明一次 |
| 长操作 | 短操作不闪忙碌提示；约 300 ms 后在所属文档显示操作与取消；有真实总量才显示百分比 | 取消不是错误；完成不重置用户已调整的视图/选择；晚到结果不得写入失效或已关闭文档 |
| 易读和可达 | 状态不只依赖颜色；按钮有文字或 Tooltip；详细设置可用键盘访问；界面使用中/日/英资源 | 在窄窗口、100%/150%/200% DPI 和两种主题下，常用入口、提示和输入不被遮挡 |

### 保留已有操作习惯

- 右键/中键平移、滚轮缩放及配置过的径向菜单保持原有分派；新增编辑工具不占用右键作为“完成”。
- grip 保持“预览后再次左键提交”，松开鼠标只释放捕获；新工具不能顺带改成拖动松开即提交。
- 画布 `Esc` 保持返回选择模式、清理选择和临时状态；布局视口既有回滚行为保留。Terminal 有建议时，`Esc` 先关闭建议。
- Terminal 的 `Enter` 先接受选中的建议；活动工具消费输入或完成当前步骤。只有空闲且无待处理输入时，才按已有规则重复命令，不能重复上一个坐标或误执行删除。
- 已有实时属性预览保留；数值字段无效时就地说明，不把暂时输入的 `-`、小数点或空文本写入模型。调整提交/撤销分组需要单独验证焦点切换、连续输入及撤销。

依据：[画布与鼠标分派](../Direct2dCad.wpf/Controls/CadCanvas.xaml.cs)、[Terminal 按键](../Direct2dCad.wpf/Views/Toolboxes/CommandLineToolboxView.xaml.cs)、[画布取消](../Direct2dCad.ViewModels/CadDocumentViewModel.cs#L750)、[当前属性控件](../Direct2dCad.wpf/Views/Toolboxes/EntityProperty/)、[现有使用约定](../README.md#基本使用)。

## M1：输入和文件可信

分成“小缺陷修复”与“文件保护”两个可独立验收的批次；不在一次改动里重写渲染或整个交互系统。

| 任务 | 实现范围与交互 | 完成标准 |
| --- | --- | --- |
| M1-01 精确坐标（F1） | 区分鼠标捕捉点和显式数值点；绝对/相对/极坐标经单位换算后不再被网格取整；回显实际提交值 | `(1.25,2.75)` mm 原样落点；英寸 `1,2` 为 `(25.4,50.8)` mm；隐藏网格/标记不影响精确值；保存重开、撤销重做一致 |
| M1-02 原点测量（F2） | 用候选存在性判断空结果；原点与零距离是合法结果；失败使用易懂的工具消息 | 通过公共 `measure_geometry`/`project_point` 入口覆盖原点、端点、线内、线外和无候选；不只验证私有函数 |
| M1-03 完整过滤（F3） | CompositePath 纳入过滤目录；“全选类型/全不选类型”操作语义清楚 | 所有支持实体在全关时都不可选；点选、框选、跨选和 SelectAll 一致；恢复过滤立即生效 |
| M1-04 打印结果（F4） | 区分提交、写入完成、取消、失败；后台失败向所属文档报告一次，可重试或打开打印设置 | 模拟后台错误和取消；没有静默吞错，也不把提交成功说成纸张已打印 |
| M1-05 覆盖保护（R2） | GUI/Terminal/AI 共用保存策略；当前文件与打开/上次保存基线一致时，正常保存无需确认；另一个已存在目标无明确覆盖授权时返回冲突；当前文件被外部修改时提供“覆盖外部更改 / 另存” | 原文件在冲突、拒绝、失败和取消时不变；明确授权范围绑定目标和版本，避免检查后文件已改变；外部修改不被普通保存静默覆盖 |
| M1-06 外部文件预算（R3） | 定义 section、解压总量、实体、嵌入内容与嵌套预算；UI、工具和恢复入口统一应用 | 超限文件被明确拒绝且当前文档有效；预算值根据固定正常样本设定，不用模糊的“无限支持” |
| M1-07 未知扩展策略（R4） | 首批对含未知 section 的图纸，仅在已识别内容可安全解析时默认只读展示；一条横幅解释原因；“另存兼容副本”在丢内容前确认 | 必需 section 版本不支持或已识别引用不完整时明确拒绝；不能普通保存覆盖源文件；兼容副本是独立目标；不把原样保留 bytes 等同于未知实体引用仍有效 |
| M1-08 自动保存与恢复（R1） | 使用一致快照写独立恢复副本；默认开启、按变更与空闲节流、限额轮换；启动只出现一个恢复入口 | 中断后原稿与恢复副本均有效；恢复为独立未保存图纸，首次保存默认另存；后台保存安静；失败可行动且不过量重复提醒 |
| M1-09 环境与响应基线 | 固定 SDK/依赖策略，建设托管 CI；选定机器与小/中/大样图；贯通现有打开/查询/保存取消与版本检查 | 记录实际使用环境、首屏、完成、峰值内存、输入延迟与取消耗时；保留未验收的原生不可抢占步骤 |

### 第一批实施顺序（已完成）

1. **M1-01 → M1-02 → M1-03**：先补能复现缺陷的针对性测试，再修业务路径；验证 Terminal、工具与真实选择入口。
2. **M1-05**：统一新路径覆盖策略，避免 GUI 与工具存在不同文件保护行为。
3. **M1-04**：补打印后台结果契约与反馈，不同时改打印比例算法。
4. 第一批完成后更新问题报告中的状态与证据，再进入 M1-06/07/08；M1-09 可独立推进。

第一批完成时不新增复杂面板，不重排全部窗口，不更改鼠标/键盘习惯。第一批验证包括相关托管回归、Release 构建及输入/过滤/错误反馈的桌面走查；没有真实打印结果时继续保留打印机验收项。

## M2：精准绘图且界面清楚

| 批次 | 建设内容 | 交互及验收 |
| --- | --- | --- |
| M2-01 捕捉开关与基础候选（G1） | 将“显示网格”“网格吸附”“对象捕捉”“标记外观”分开；先支持端点、中点、圆心，再做解析交点；可视容差使用屏幕距离 | 默认新图纸对象捕捉开、网格吸附关、正交关；旧图纸迁移保留原鼠标网格吸附行为并显示状态；当前候选用形状+短名称提示，不弹窗 |
| M2-02 稳定候选 | 屏幕容差、优先级、候选保持、必要的候选切换；查询使用空间索引，处理布局视口和嵌套块变换 | 指针缓慢移动不反复跳点；隐藏/擦除实体和当前预览不误捕捉；缩放、DPI、单位变化不改变几何精度 |
| M2-03 正交与极轴 | 先做正交，再做极轴跟踪；两者模式和优先级明确；端点外的垂足/相切捕捉随后扩展 | 状态栏能一键切换，详细角度按需展开；显式坐标优先于跟踪约束；不静默投影输入点；快捷键先查现有冲突再确定 |
| M2-04 操作提示与参数（G7） | 画布动态输入复用工具步骤、精确输入与取消状态；样式参数放原属性区域，复杂命令使用 Terminal；本地化 HELP 和示例 | 当前步只有一条主提示；Tab 切换字段，已输入值固定并实时预览；无效几何保留之前的点、当前步与输入；无需 Terminal 也能完成标准绘图和新编辑工具 |
| M2-05 属性与状态栏 | 属性区分新建/已选/多选，多种值明确；常用线型直接可达，端帽/连接展开；状态栏恢复原横向样式，保留简短状态、单位、网格类型/主次间距和常用捕捉/约束图标 | 图标保留选中态、键盘操作和文字提示；极轴角度、垂直/切线捕捉、标记和背景从状态栏图标按需展开；窄窗口保持一行；面板可以隐藏、浮动并记忆布局 |

按最新用户反馈，画布在对应尺寸位置或光标旁显示紧凑数字框，不显示大面板、步骤标题和快捷键提示；数字框按内容调整宽度，用 Tab / Shift+Tab、Enter 和 Esc 操作。光标旁的数字与模式图标同一行，图标在最左边，背景半透明；整行一起避让边缘。候选切换使用 Ctrl+Tab。“绘图辅助”工具箱仅保留恢复稿入口，启动时没有恢复稿则收起、有恢复稿则显示；仍保留布局持久化及原侧栏/状态栏入口。状态栏保持原有横向风格，单位、网格类型和主次间距仍在底部；常用勾选项改为图标开关，文字放悬停提示。视图与捕捉详情集中到状态栏弹出面板，恢复入口使用图标，保持底栏紧凑。高级圆弧和椭圆目前使用 X/Y，完整动态参数集合尚未实现。

验收样例：不打开设置窗口，画一条从已有端点到另一圆心的直线；一键关捕捉后自由绘图；直接输入小数坐标；切换工具后描边默认值仍正确，`Esc` 后无残留预览。

## M3：完成常用改图

先建立统一的几何公差、曲线参数和明确的引用方式，再逐种实体扩展命令。每批声明支持范围，不让不支持的实体部分成功或悄悄近似替换。

基础命令先在直线、圆/圆弧等已支持几何上交付；复杂曲线自适应测量、任意方向椭圆/矩形及椭圆弧变换独立推进，不阻塞基础修剪/偏移。M4 只依赖稳定的引用与变更契约，不等待全部 M3 编辑命令完成；新增尺寸实体的契约可以提前设计，关联更新随相应几何路径逐批验收。

| 批次 | 范围与依赖 | 主要交互 |
| --- | --- | --- |
| M3-01 几何基础（G6/G8） | A：直线/圆弧公差、求交、解析长度/面积与引用更新规则；B：复杂曲线自适应计算及误差说明；C：方向表达与矩形/椭圆/椭圆弧变换。A 是基础编辑前置，B/C 独立交付 | 正常结果只显示数值和单位，近似结果显示 `≈`，误差详情按需展开；不支持的变换给具体原因 |
| M3-02 偏移（G2） | 先直线、圆、圆弧，再多段线；明确尖角、闭合、自交、距离过大和退化规则 | 输入距离 → 选对象 → 悬停一侧预览 → 左键提交；预选对象时省略选对象步骤；每次创建对应一次撤销；连续操作记住距离，Enter 完成连续模式 |
| M3-03 修剪/延伸（G2） | 边界求交、公差和段选择，先直线/圆弧，再混合曲线；已提交每次编辑有独立撤销记录 | 默认采用预选边界，或“选择边界 → Enter → 悬停预览 → 左键提交”；修剪只高亮将移除段，延伸显示所选端的新增段；自动推断边界留作后续明确选项 |
| M3-04 圆角/倒角（G2） | 依赖偏移与求交；先两段线，再曲线连接；半径/距离、方向和裁剪策略同步入历史 | 两个对象 → 半径/距离 → 看预览 → 提交；常用参数在原属性区域，记住本工具上次值；失败保留输入便于修改 |
| M3-05 拓扑编辑与阵列（G2） | 分批连接、打断、矩形/环形阵列；先定义容差、复制依赖和关联支持范围 | 复用选区与预览；数量/间距错误就地提示；批量结果作为明确操作批次撤销，不逐实体确认 |

修剪/延伸/偏移的连续模式下，每次点击已提交结果保留；`Esc` 只退出并清理当前预览，撤销由原历史入口处理。不能把“退出工具”混同于撤销整个已完成编辑序列。

验收同时覆盖多交点、相切、零长段、微小半径、闭合路径、块引用变换和失败回滚。每种新结果必须完成 bounds、命中、属性、grip、保存/重开、打印与 undo/redo 接入。

## M4：完成工程标注

对应问题报告的 G3（关联标注）和 G7（模板及用户工作流）。

- **M4-01**：尺寸实体、尺寸样式、稳定几何引用及版本化存储；先做线性、对齐、半径/直径，再做角度和引线。先稳定模型、公差及引用规则，避免靠实体序号或最近位置猜关联。
- **M4-02**：默认“选择几何/两个基准点 → 移动预览标注位置 → 点击放置”。两种输入共享流程，工具提示说明当前可选内容；重复放置沿用样式，不每次打开样式对话框。
- **M4-03**：双击或属性面板编辑标注；常用项是样式、单位、精度，字体/箭头/偏移等高级项展开。手动替换显示文字需明确可见，避免替代文字被误认为实际测量值。
- **M4-04**：关联失效显示可见标记并提供重新关联/解除关联；删除、拆分、合并或无法唯一映射时不猜测新目标。复制、块编辑、撤销重做和重开后遵循同一策略。
- **M4-05**：提供少量工程模板和推荐尺寸样式，明确图形单位、纸张、视口比例及注释字号；完整参数约束另行排期。

验收：同一零件修改后，关联尺寸自动更新；不能映射时明确失效；布局打印中的字号与箭头保持设定纸面尺寸；样式、关联和数值经过复制与保存重开不变化。

## M5：完成图纸交付

### M5-01 工程比例打印（G4）

复用现有打印预览。清楚区分 **模型视口比例** 与 **整纸缩放**：例如模型视口 `1:100`，整纸 `100%`，不能在输出时再次暗中 fit。

- Layout 默认保留纸张物理尺寸；预览一行“纸张缩放：实际尺寸 / 适合纸张 / 自定义”，自定义数值仅在选中后显示；DPI 等高级项折叠。
- 显示可打印边界和裁剪部分；选择实际尺寸后不因超出边界自动改成 fit。
- 预览和提交共用驱动校验后的纸张、方向、可打印区域与比例计算；打印机或设置变化立即刷新预览，不能在最终提交时偷偷换比例。
- model space 输出明确选择范围、纸张和比例；文字、线宽与栅格内容的输出策略统一。
- 验收 100 mm 校准线、1:100 样图、PDF 驱动与真实打印机；提交/完成/取消/失败复用 M1-04。打印驱动写入完成不代表纸张已物理输出。

### M5-02 DXF 交换（G5）

先确定版本、支持实体、单位和文字/线型映射矩阵，再实现基本直线、圆/圆弧、多段线、图层、块与文字；样条、Hatch、特殊字型、OLE 和关联标注按能力分批。

- “打开 DXF”默认生成新文档；“导出 DXF”保留 `.d2cad` 源稿和当前保存路径。
- 单位可靠时直接处理；缺失或冲突时集中询问一次。不能自动猜单位并静默缩放。
- 有损导出在写入前显示一次摘要，可展开详情；导入结束仅显示“导入 1054 个对象，12 项未支持”等真实统计，不逐个弹窗。
- 依赖外部文件预算和覆盖保护；取消/失败不留下看似完整的半成品文件。未知 DXF 对象的策略须单独定义，不能假定容器 section 策略自动适用。
- 使用固定外部 CAD 样本双向往返验证几何、单位、块、层、文字和比例；DWG 在确定 SDK、许可与目标需求后另列阶段。

## 每阶段怎么判定完成

“代码有了”“测试通过”和“交互可用”分别记录。任务记录使用下面五项：

1. **实现**：已支持实体/流程和明确限制；所有入口共享的业务行为。
2. **自动验证**：针对边界的测试、受影响回归与构建；保存/变换/关联等必须检查失败路径和重开。
3. **交互验收**：真实桌面完整操作；记录输入、提示、点击、焦点、预览、取消和撤销，不用 ViewModel 测试替代。
4. **专项证据**：涉及打印、外部 CAD、OLE、GPU/DPI、性能或安装时，分别保留对应环境与结果。
5. **文档状态**：更新本规划及问题报告，标注待做/进行中/代码完成待交互验收/已验收；未运行的项目明确保留。

统一桌面检查：首次使用者可仅凭提示完成标准任务；常用捕捉开关一次点击，详细配置至多再展开一层；正常绘图无需模态对话框；无须输入 JSON；错误后可修改重试；`Esc` 后无捕获/预览残留；小窗口和高 DPI 下核心操作可达；多选的不同值不会误写为零。

阶段验收固定样图逐步扩展：小数坐标线段 → 带圆弧零件和偏移轮廓 → 关联尺寸及块 → Layout 工程纸张 → DXF 往返；另设大图纸、损坏/超限文件和中断恢复样本。样本与预期结果入库，实际机器测量结果按日期存放。
