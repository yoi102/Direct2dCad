# 文档菜单、恢复生命周期与 Ribbon 焦点

2026-10-03，Windows，Release。恢复、清除、进程终止测试全部使用独立的临时 settings／recovery 目录，未清除用户现有恢复稿。

## 行为

- 文档条目右键提供切换、保存、打开所在文件夹、关闭；命令绑定到点击的条目。未保存文件禁用定位文件夹，关闭仍遵守保存／不保存／取消。
- 恢复条目提供真正独立的右侧打开和清除按钮、全部清除及同类右键菜单。名称省略、时间、垂直滚动和键盘空格打开保留。
- 恢复列表使用有集合自动化支持的 ListBox，避免更新后显示正常、UI Automation 却找不到新条目的问题。保持紧凑行样式。
- 恢复快照带会话 ID，运行中的会话持有文件租约；只展示已结束会话的遗留快照。旧版无会话标记的稿件仍可恢复和手动清除。
- 单图纸及应用“不保存”关闭都取消并等待进行中的备份，然后删除相应恢复版本。取消或保存失败不终止保护；清除只移除可恢复版本，不删除原图或其他活动会话的快照。
- 恢复稿打开后保留原始恢复版本，待恢复图纸保存或明确关闭时清理。
- Ribbon 首个按钮的白框来自自动转移的键盘焦点。移除把所有键盘焦点画成实框的样式，保留仅键盘导航显示的虚线 FocusVisualStyle；实际模式继续用 IsChecked 高亮。
- 文档列表关闭／重建时继承的主题样式出现 Cursor、VerticalContentAlignment、ShowSelection 三条祖先绑定错误。使用本地模板和稳定属性值保留选择／悬停外观，未降低绑定诊断等级。

## 验证

- Release 全解决方案构建：0 warning、0 error；相关差异空白检查通过。
- 文件恢复服务：9/9，包含活动／异常会话隔离、清除全部版本、原文件保留以及备份写入与正常会话结束的竞争。
- 文档菜单／恢复／关闭／工作区工具 ViewModel：63/63，包含关闭非活动图纸、取消、保存失败和正在写入时不保存关闭。
- 窗口检查涵盖中文深色、英文浅色、900×700 和 1300×900、真实鼠标右侧点击、菜单条目目标、键盘恢复、空列表、欢迎页和图纸页切换、模式选中状态。恢复／Ribbon 的 7 条路径通过；文档菜单样式修复后单独复测 1/1，通过并记录空绑定日志。
- 真实异常终止：正常编辑 → 等待正式 60 秒定时器产生备份 → 活动会话仍无恢复条目 → 强制结束隔离应用进程 → 原目录重启 → 通过右侧按钮恢复并验证 1 个实体 → 取消关闭后仍保留 → 不保存退出 → 原目录再次重启无恢复条目，1/1 通过。
