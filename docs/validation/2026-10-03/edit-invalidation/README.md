# 曲线编辑后的显示与选取修复

2026-10-03，Windows x64、SDK 10.0.401，本地未提交工作区。此专项独立于此前 M1–M6 回归和分发包。

## 录像观察与原因

用户录像 `PixPin_2026-10-03_17-19-36.mp4` 长 8.4375 秒。逐秒采样可见线段在缩放中消失、再出现；录像没有展示完整打断过程，不能仅凭画面判断数据库是否生成新实体。

代码及修复前回归确认：`EditCurvesCommand` 已创建打断后的两个独立实体并擦除原件，但向每个相关 ID 同时报送 `Created | Deleted`。`CadDocumentChangeDispatcher.UpdateSpatialIndex` 按 `Deleted` 移除索引，连活着的新段也被移除。画布的可见候选查询和鼠标命中都依赖该索引，这足以解释重绘后的缺段和选取失败；录像中的短暂重现可能来自缓存/缩放预览，本次未逐帧追踪其具体分支。

偏移、修剪、延伸、圆角、倒角和连接共用该命令，确有相同问题：新创建的结果、保留 ID 的修改实体均被错误移出索引。旧原生偏移测试没有接入空间索引查询，因此只证明资源更新，未覆盖产品使用的候选过滤路径。

## 修复

`EditCurvesCommand` 按每个实体分别通知：保留 ID 的曲线为 Geometry/Appearance；擦除的原件为 Deleted；新段为 Created。撤销恢复原件、擦除新段；重做恢复同一组结果 ID，不重复创建实体。

`CadCommandGeometryChanges` 增加接受逐实体变更的重载，受影响的嵌套块引用仅报告 Geometry，不能继承子实体的 Created/Deleted。标注关联继续保持原有规则：分裂和连接不会猜测新实体引用。
