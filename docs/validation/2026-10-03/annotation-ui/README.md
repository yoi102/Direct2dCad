# 标注面板与窗口交互验证

2026-10-03，Windows x64、.NET SDK 10.0.401，本地未提交工作区。此次验证针对标注属性、欢迎页上下文、画布光标和窗口文件菜单，独立于 M1–M6 完整回归及分发包。

## 通过结果

Release 应用和 UI 测试项目构建通过。最初 ViewModels 专项 **69/69**，覆盖当时的标注参数创建、手动应用、关联、非法值、撤销重做，欢迎页/工具箱/图纸上下文切换，以及绘图与平移状态。该历史结果的 TRX 位于 `TestResults/annotation-properties/final-viewmodels`。

后续按用户要求去掉标注“应用”按钮，字体、箭头、数值和替代文字均实时写入所选标注；绘制时更新预览和默认值。输入期间保持位置、基准点和关联，一个输入框中的连续输入按默认批次历史一次撤销，预设样式整体一次撤销。加载选择和撤销同步不会产生新命令；非法值、锁定对象和只读图纸不会写入。

实时修改后的 ViewModels 专项 **45/45**（其中标注工作流 **35/35**，另含欢迎页生命周期与绘图辅助），真实窗口专项 **2/2**（标注属性与欢迎页）。TRX 位于 `TestResults/annotation-properties/live-viewmodels-final` 和 `live-ui`，这些结果与历史结果分别记录，不累加。真实窗口检查连续输入后一次撤销、数值独立撤销、预设整体撤销、滚动、无应用按钮及工程模板；截图已更新。

本轮标注交互进一步简化：标注模式隐藏绘图辅助的整组步骤控件，下一步提示收进状态栏当前模式的悬停提示和无障碍说明。确认基准点后显示 8 像素直径的小圆点，预选引用也显示对应基准点；缩放和指针离开画布后保留，放置、完成、取消或切换工具时清除，标记不进入文档或历史。

本轮 ViewModels 专项 **45/45**（标注工作流 44 项、绘图辅助 1 项），TRX 位于 `TestResults/annotation-properties/point-markers-viewmodels`。真实窗口本轮按唯一用例最新结果 **4/4**：标注控件隐藏与可见点标记、标注属性、欢迎页、窄窗口绘图/编辑。前 3 项同轮通过，窄窗口用例早期在网格点击/通知等待处超时；测试准备改为聚焦窗口并把鼠标移开通知区域后，独立重跑通过，未为此修改产品代码。失败记录保留在 `point-markers-ui`、`point-markers-narrow-ui` 和 `point-markers-narrow-diagnostic`；通过记录在 `point-markers-narrow-final`。Release 应用及 UI 测试构建零警告、零错误。

本阶段真实窗口专项按各用例的最新结果汇总 **6/6**，其中 4 项来自基准点标记阶段，光标与文件菜单 2 项使用之前记录；不累加重复运行。每项对应的 TRX 见 [verification.json](verification.json)。

后续已把绘图和标注数字输入移到画布小框，移除右侧整组步骤控件；光标旁数字与半透明模式图标同行，完整步骤仅放状态栏悬停提示。当前行为及独立模型 **119/119**、同轮真实窗口 **10/10** 见[动态输入专项](../dynamic-input/README.md)。其中本页的欢迎页、窄窗口、光标、标注属性和基准点 5 项均已重跑通过，窗口文件菜单继续使用此前记录；这些结果不与历史次数累加。

后续按用户要求，绘图、定位、编辑、标注和粘贴均保留普通箭头，当前工具图标显示在右下角。本次调整重新运行绘图流程 **49/49**、光标真实窗口专项 **1/1**；其余四项 UI 使用前一轮记录。图标资源覆盖 43 个活动工具模式及粘贴，此资源检查不计为 43 项运行时测试。

位置标记也改为在关闭网格吸附时显示：未吸附的坐标保持原值，指针恰好落在网格点时仍显示，标记类型为“无”时隐藏。捕捉服务专项 **16/16**，真实窗口专项重跑 **1/1**；截图在网格吸附关闭时采集，位置标记和工具图标同时可见。
