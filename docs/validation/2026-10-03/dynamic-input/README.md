# 画布动态输入验证

2026-10-03，Windows x64、.NET SDK 10.0.401，本地未提交工作区。此次专项覆盖画布动态输入及相关窗口交互，独立于早期 M1–M6 回归及分发包。操作说明见[绘图与编辑](../../../DRAWING-AND-EDITING.md#精确输入和捕捉)。

## 当前行为

画布只显示小数字框：圆半径/直径和直线长度放在尺寸辅助线上，矩形宽高分别贴在对应边旁。坐标、角度和样条输入位于光标右下角，与模式图标排成同一水平行，图标最左边，背景半透明。数字框高 24 DIP，宽度按内容在 48–112 DIP 间调整；整行在画布边缘避让。不显示大面板、标题或常驻快捷键提示，灰色虚线不进入图纸。

`Tab` / `Shift+Tab` 切换数字，画布直接键入数字进入第一字段，输入实时固定数值并更新预览；字段内 `Enter` 或画布点击接受当前点。未编辑字段继续跟随鼠标，确认使用完整精度；非法值保留步骤，`Esc` 取消，`Ctrl+Delete` 释放固定值。单位按文档单位显示和输入。连续绘图接受点后，再在画布按 `Enter` 完成。

右侧“绘图辅助”不再有步骤输入、完成或取消按钮，仅保留恢复稿入口；没有恢复稿时启动收起。标注属性仍实时更新，已确认基准点仍保留小圆点，步骤说明位于状态栏当前模式的悬停提示。

## 已修复问题和保留记录

早期大浮层拦截画布点击、空恢复面板启动展开，以及焦点断言读取早于切换完成的问题均已修复或调整检测时机，探索记录保留在 `TestResults/dynamic-input`。

`ui-compact-final` 曾为 8 通过、2 失败。Windows .NET Runtime 事件证实矩形字段容器逐个生成时发生 `KeyNotFoundException: Height`，导致产品退出。现将位置更新合并到 Render 调度，并在矩形分支同时检查宽高字段；最终矩形和原直线流程均通过。此失败属于产品崩溃，未归类为 UI 自动化抖动。

`ui-inline-first` 为 3 通过、1 失败，仅矩形灰线像素断言失败。`ui-rectangle-guide-diagnostic` 截图确认虚线已绘制，抗锯齿像素为灰色约 55，原检测下限 70 未覆盖；现检测下限为 40，仍排除约 33 的网格像素。独立矩形复跑 1/1、最终完整轮 10/10 通过，未删除虚线可见性断言。上述失败 TRX 保留。

## 范围边界
