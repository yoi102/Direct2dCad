## 实现边界

- 几何编辑支持直线和圆弧组成的精确路径。Spline、椭圆/椭圆弧、圆角矩形不在这批修剪/偏移/连接能力中，明确拒绝；其测量、保存及适用变换仍可用。椭圆绘制已保留第一轴方向，支持直接构造倾斜椭圆及椭圆弧；见[绘制修复与验收](DRAWING-FIXES-2026-10-07.md)。
- 圆角/倒角支持单独直线、圆弧。完整圆需关闭裁剪或先打断为圆弧；多段路径角点明确拒绝。连接要求 owner、图层、外观、线宽来源、可见性和绘制顺序兼容，不能猜测 M4 关联目标。
- 对象捕捉每次最多访问 4096 实体、嵌套深度 32；交点使用前 128 个解析 primitive。非均匀缩放块中的圆保留基础候选，尚未扩展解析椭圆交点/相切。
- 阵列每批最多 10000 个结果实体，预览最多展示前 256 个位置；实际提交量和撤销批次一致。
- 文件默认上限：512 MiB 文件/总解压、256 MiB 单 section/嵌入内容、100 万实体/集合项、64 层数据、32 层块、64 Mi 像素、16 MiB 单字符串。样图及其哈希已记录；这些是保护预算，不能推断预算以内的任意文件均能流畅处理。
- 保存在准备与替换前检查文件版本，再以同目录临时文件提交。检查与替换不是操作系统级的跨进程 compare-and-swap；不宣称完全消除其他进程同时写入的最后竞争窗口。
- 长度误差为估计值；复杂曲线投影/求交返回细分曲线距离界，它不等同于相切附近的交点坐标误差保证。达到预算时明确报告，不静默称为精确结果。
