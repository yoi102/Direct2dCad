## 精确输入和捕捉

切换“绘制／修改／标注”页签只改变工具栏页面，不启动工具。按钮高亮表示实际启用的模式；通过键盘 Tab 导航时，虚线框仅表示键盘焦点。

先从 Ribbon 选择工具。画布只显示小数字框：长度、半径/直径、圆弧角度和椭圆半轴贴在对应的尺寸辅助线上，矩形宽高分别位于横边和竖边旁。点坐标、直线角度或样条输入仍位于光标右下角，与模式图标排成同一水平行，图标在最左边，背景半透明。不显示整块面板、步骤标题或常驻快捷键说明。短数字使用窄框，较长数字按内容适当扩展，靠近边缘时输入避让；灰色虚线仅为临时尺寸辅助，不进入图纸。右侧“图纸恢复”不再显示坐标输入或完成/取消按钮，仅保留恢复稿入口，启动时没有恢复稿则自动收起。

无需打开 Terminal，画布直接键入数字即可编辑第一个字段，`Tab` / `Shift+Tab` 在字段间循环，`Enter` 确认当前点或尺寸，`Esc` 取消。也可以点击数字框编辑：第一次点击或点击仍在跟随鼠标的数值时全选，已固定且有焦点的字段允许定位光标修改。点选输入框以外的画布确认当前步骤。所有字段左侧显示 `X:`、`Y:`、`R:`、`D:`、`A:` 等简短标识，角度右侧保留 `°`；数值框高 24 DIP，宽度按内容在 56–128 DIP 内调整。

起点提供 X/Y，直线、多段线、多边形和样条的后续点提供长度/角度，矩形第二点提供宽/高并沿鼠标所在象限展开。已修改字段用强调色边框区分并固定数值，未修改字段继续随鼠标更新；输入立即更新预览，确认前不增加实体或撤销记录。`Ctrl+Delete` 释放固定值并恢复原构造点和鼠标预览。显示精度使用文档设置，不使用科学计数法；未编辑字段确认时仍使用完整几何精度。

| 曲线步骤 | 可编辑参数 |
| --- | --- |
| 圆：中心半径／中心直径／两点直径／三点圆最后一步 | `R:` 半径或 `D:` 直径，贴在实际半径或直径线上 |
| 圆弧：中心与起点步骤 | `R:` 半径 |
| 圆弧：端点、角度、弦长、半径或切线方向步骤 | `A:` 扫角、`L:` 弦长、`R:` 半径或 `D:` 切线方向角，按所选构造方式显示 |
| 三点圆弧／连续圆弧 | `R:` 半径与 `A:` 扫角 |
| 椭圆：确定第一条轴后 | `X:` 和 `Y:` 两个半轴长度，可同时修改；此处不是光标坐标 |
| 椭圆弧：起始角／结束角步骤 | 保留 `X:`、`Y:`，再提供 `A:` 起始角或扫角 |

椭圆中心方式固定中心，轴端点方式固定第一个轴端点；修改第一半轴时相应调整另一轴端点。椭圆弧修改半轴时保留已确认的起始参数角。扫角必须大于 0 且小于 360°；三点圆和圆弧的半径不得小于已确认弦长的一半，圆弧还必须经过已确认的中间点，弦长不得超过直径。不相容参数显示简短错误并保留步骤，不会静默改变输入值。曲线参数专项证据见[2026-10-04 验证](validation/2026-10-04/curve-dynamic-input/README.md)。

连续绘图在字段内按 `Enter` 接受当前点并回到画布，再按 `Enter` 完成当前工具；也可通过 Terminal 的 `DONE` 完成。标注同样支持画布动态输入，基准点确认后保留小圆点。下一步的完整说明位于状态栏当前模式的悬停提示，输入框也提供无障碍快捷键说明。切换工具会清除未确认的固定值；隐藏或重开工具箱不会丢失画布输入。

Terminal 继续支持以下输入语法：

| 输入 | 含义 |
| --- | --- |
| `1.25,2.75` | 当前文档单位的绝对坐标 |
| `@10,0` | 相对上一个接受的点移动 X=10、Y=0 |
| `@20<45` | 从上一个接受的点向 45° 方向移动 20 |
| `10` | 直线的当前方向长度、圆的半径/直径，或偏移/圆角/倒角的距离参数；仅适用于相应步骤 |

显式坐标不会再次网格取整，也不受对象捕捉、正交或极轴修改。动态输入使用当前文档单位，角度使用度；支持当前区域的小数格式和小数点 `.`，Terminal 使用小数点 `.`。文档几何内部使用毫米。非法数字、非有限值或非正尺寸会提示错误并保留当前步骤，可以修改后重试；共线三点圆/圆弧、零尺寸图形同样保留之前的点。

状态栏保持原来的横向一行，显示简短工具名、坐标和单位；网格类型、主网格间距、次网格间距仍在底部直接调整。“网格捕捉 / 对象捕捉 / 正交 / 极轴”改为图标按钮，选中时有高亮边框和底线，悬停显示名称，也可以用 Tab 聚焦后按空格切换。新图纸默认对象捕捉开启，其余关闭；旧格式迁移保留之前的网格捕捉行为。网格是否显示与是否吸附分开。正交与极轴互斥；显式输入保持原值。

对象候选使用标记和名称提示，有多个候选时在画布按 `Ctrl+Tab` 切换。点击状态栏的“视图与捕捉详情”图标可以设置极轴角度，启用垂足/相切捕捉，调整原点、捕捉标记和背景。

## 常用编辑

在 Ribbon 的“修改”组选择工具。参数显示在现有属性区域，只展示当前工具适用项；预选对象可省去部分选对象步骤。距离和间距使用文档单位，角度使用度。

| 工具 | 操作 |
| --- | --- |
| 偏移 | 设置距离 → 选对象（或预选）→ 悬停一侧查看预览 → 左键提交；可继续在另一侧创建，画布 Enter 结束 |
| 修剪 / 延伸 | 选择边界（或预选）→ 画布 Enter → 悬停目标段 → 左键提交；修剪标出移除部分，延伸显示新增部分 |
| 圆角 / 倒角 | 设置半径或两个距离 → 选择两个对象及保留侧 → 检查预览 → 左键或画布 Enter 一次提交；可选择是否裁剪原曲线 |
| 连接 | 逐个选择兼容链段（或预选）→ 画布 Enter；要求端点可连续连接、外观及空间兼容 |
| 打断 | 选对象 → 第一个断点 → 第二个断点；第一断点后画布 Enter 表示单点打断 |
| 矩形阵列 | 选对象 → 画布 Enter → 修改行/列与 X/Y 间距 → 看预览 → 左键或画布 Enter 提交 |
| 环形阵列 | 选对象 → 画布 Enter → 指定中心 → 修改数量、总角度与副本旋转 → 看预览 → 左键或画布 Enter 提交 |

偏移、圆角、倒角各自记住当前文档会话内的参数。预览不写入实体或历史；失败显示原因，保留参数便于修改。修剪、延伸和偏移每次提交独立可撤销；阵列整体为一次批次。

单点打断会生成两个独立结果，两点打断移除两点之间的部分并保留剩余结果；每段都可分别选取和继续编辑。单一存活曲线尽量保留 ID，分裂/连接生成新 ID，关联标注不会按最近位置猜测重新绑定。编辑结果在缩放、撤销和重做后继续参与显示及命中查询；2026-10-03 的变更通知与索引修复见[专项验证](validation/2026-10-03/edit-invalidation/README.md)。

`Esc` 退出并清理未提交的预览，连续工具已经提交的结果保留。用现有撤销入口回退结果。右/中键平移、滚轮缩放和配置的径向菜单保持原操作；grip 仍采用预览后再次左键提交。

画布在选择、浏览、绘图、定位和粘贴预览时均显示普通箭头，平移或移动 grip 时显示手形。活动工具的小图标跟随箭头右下角，沿用 Ribbon 图标并使用半透明背景；有光标旁的数字输入时，图标位于同一行最左边。普通选择、平移、菜单和离开画布时隐藏图标。靠近边缘时图标及输入移到画布内，不拦截鼠标点击。退出平移或拖动后恢复箭头；菜单和工具箱使用各自控件的光标。

捕捉标记的显示与网格吸附开关分开：未启用吸附时标记跟随实际位置，启用后显示接受的吸附位置，指针恰好位于网格点时也保持可见。标记仍沿用设置的形状、大小和颜色；选择“无”可隐藏位置标记。

在布局中开始“创建视口”时，布局设置面板会自动收起，避免遮挡画布角点。指定两角后可调整视口，第三次点击结束调整并回到纸张空间；随后可通过 PAPER / MODEL 切换。

精确编辑的实体范围、圆角限制、阵列和捕捉预算见[实现边界](M1-M3-STATUS.md#实现边界)。Spline、椭圆等不支持的编辑会拒绝，不会暗中换成折线。

## 布尔操作与面域

Ribbon 的“修改”页新增并集、交集、差集三个图标按钮，悬停查看名称；画布右键的“布尔操作”子菜单提供相同入口。至少选中两个受支持的闭合实体，且全部可编辑、位于当前编辑空间时才启用。锁定或只读对象、开放曲线以及不支持的实体会使入口禁用。

并集保留所有覆盖区域，交集保留所有选中对象共同覆盖的区域。差集开始后，在画布点击要保留的主体，再从主体中扣除其余选中对象；优先点击主体边缘，重叠边缘按图层显示优先级及实体顺序拾取。内部点只有能唯一确定主体时才接受，不使用多选先后顺序猜测主体。

主体以橙色标出，结果边界以绿色预览；`Enter` 确认，`Esc` 取消。预览不修改原图，也不产生撤销记录；确认后用一个面域替换来源实体并自动选中，整次操作可一次撤销、重做。后台计算可取消，取消后不会回现旧预览。空结果、自交或精度/预算限制会保留原对象并显示错误；步骤说明位于状态栏当前模式的悬停提示。布尔模式只显示光标模式图标，不显示无关的坐标输入框。

当前支持圆、全圆圆弧、普通矩形、闭合多段线、由直线/圆弧组成的闭合复合路径，以及已有面域。圆角矩形、椭圆、样条和开放曲线尚不支持，不会自动转成折线。单次输入最多 2048 条边，排列及结果最多 32768 条边；低于几何容差、无法可靠闭合的结果会拒绝提交。

面域（`CadRegion`）可包含多个分离区域和孔洞，边界保留解析直线与圆弧。所有轮廓均参与显示、边缘选取和对象捕捉，孔洞不作为填充材料命中；属性提供面积、总边界长度、轮廓数以及实时描边/填充设置。支持整体移动、旋转、镜像、等比缩放、复制粘贴、原生 `.d2cad` 保存重开和矢量打印几何。

布尔结果确认后自动选中，显示一个圆形中心移动点和四个方形外框角点。点击中心点、移动鼠标，再点击目标位置可整体移动；多选时一同移动可编辑对象。点击角点可围绕对角等比缩放，移动过程中实时预览，圆弧仍保持圆弧，孔洞和分离区域一起变换。`Esc` 取消未确认的操作，提交后一次撤销；锁定对象不显示控制点。沿用其他实体的点击预览再点击确认操作，松开鼠标不自动提交。中心点即使位于孔洞或分离区域之间也可拾取。当前不提供逐顶点拉伸，也不将孔洞或分离区域交给单条曲线的修剪、打断、偏移工具处理。验证见[面域控制点专项](validation/2026-10-03/region-grips/README.md)。

含面域的图纸使用新的版本化 section，旧版软件会进入已有的兼容只读保护。面域暂不能导出为 DXF，导出前会列入损失摘要并要求明确确认，详见[交换支持矩阵](ANNOTATION-AND-EXCHANGE.md#dxf-支持矩阵)。本机验证见[布尔操作专项](validation/2026-10-03/boolean-regions/README.md)。

## 属性与 Terminal

属性顶端区分新建设置、已选实体和多选；多选不同值显示“多种值”。常用线型直接可见，端帽/连接等在展开区域，不适用字段按能力隐藏。绘制默认值跟随预览与新对象，在当前文档会话按类型保留。

欢迎页的属性、图层、块、实体搜索和选择过滤工具箱显示简短的打开或新建提示，隐藏图纸编辑控件。切回图纸后恢复该图纸的工具与属性；点击工具箱不会改变当前图纸上下文。

椭圆、椭圆弧、矩形可以编辑方向，并参与旋转/镜像及适用缩放。曲线长度带单位，近似值显示 `≈`；鼠标停留可查看误差估计和预算提示。

Terminal 的 `HELP` 使用当前界面语言，列出命令和输入示例。新命令为 `OFFSET`、`TRIM`、`EXTEND`、`FILLET`、`CHAMFER`、`JOIN`、`BREAK`、`RECTARRAY`、`POLARARRAY`；`DONE` 完成当前步骤，`CANCEL` 退出。Enter 有命令建议时先接受建议，Esc 先关闭建议。

## 保存、兼容副本和恢复

正常保存不弹成功对话框。若源文件已被其他程序更改，会同时提供“另存 / 覆盖外部更改 / 取消”；默认按钮为另存。取消、冲突或保存失败时保留原稿。另存目标已经存在也受覆盖检查保护。

含未知扩展但已识别内容可安全解析的图纸以只读方式打开，横幅说明原因。“另存兼容副本”需要独立目标，并在丢弃未知内容前确认；源文件不会被普通保存覆盖。必要格式或已识别依赖无法解释时拒绝打开。

文档管理列表支持条目右键菜单：切换到此图纸、保存、打开所在文件夹和关闭。菜单操作针对右键点击的图纸；关闭有修改的图纸仍提供保存、不保存和取消。未保存图纸没有文件位置，文件夹菜单禁用。

自动恢复默认开启，可在一般设置关闭。应用每 60 秒检查有修改且至少空闲 5 秒的图纸，后台写独立恢复副本；每张图纸在同一会话保留 3 版，总预算 256 MiB。恢复列表只显示已结束会话遗留的副本，正在运行的会话不会进入列表。正常保存、正常关闭图纸或退出应用时选择“不保存”，会清除相应恢复稿；取消关闭或保存失败继续保留保护。备份正在写入时，关闭会先取消并等待它结束，避免清除后再次出现。

恢复条目点击名称仅选中，点击右侧恢复图标或右键菜单的打开项才恢复；键盘可选中条目，再 Tab 到恢复按钮并按空格打开。已打开的同一恢复稿再次恢复时，切换到现有图纸，保留编辑内容，不重复添加 Documents。文档与恢复列表均以左侧主题色竖条表示选中，以半透明背景区分悬停和选中，随明暗主题变化。右键菜单还可定位恢复稿／原图文件夹、单项清除或全部清除。清除会删除对应图纸的所有恢复版本，保留原图和活动会话的备份。恢复打开为独立未保存图纸，首次保存选择目标；打开成功后暂时保留原恢复稿，直到恢复图纸保存或明确关闭。旧版本没有会话标记的恢复稿继续保留，可手动清除。

打开、保存和查询超过约 300 ms 显示所属文档的操作提示与取消入口。取消为协作取消；原生准备等不可抢占步骤的响应限制见[性能记录](validation/2026-10-03/README.md)。打印提交和驱动写入完成分别反馈，驱动完成不代表纸张已物理输出。
