## 实施原则

- 原有未提交的 Region DXF 导出改动保持原样，不把它们算作本轮成果。
- 明确应用、文档、渲染会话和 worker 的所有权；关闭文档不依赖应用退出回收。
- 共享执行规则不混合 `ICadCommand` 与 `ICadEditorCommand` 的语义。
- 应用服务依赖中性契约，WPF 负责 Dock、窗口、系统集成和后端装配。
- 快照保持线程隔离；异步结果继续校验文档版本、存活状态及活动空间。
- 源码实现、托管回归、原生集成、真实桌面验证分别记录。构建通过不代表设备或 UI 验收通过。

## 策略与后续边界

- 历史预算分别作用于文档和编辑器历史；保留最新完整命令/批次，即使它超过软预算。预算不包含实体数据库本身，也不是整个进程内存上限。
- 默认渲染优化缓存额度为进程 1 GiB、单文档最多 512 MiB，由主渲染器和并行 worker 共享。`RENDERSTATS` 提供各层估算占用和额度。帧/准备步骤结束后执行裁剪，正在使用的资源、基础几何、画刷/文字布局、CPU 图纸数据及呈现表面不在该额度内。
- 本轮没有测量大图纸长期工作集、实际显存峰值、显示器 FPS 或物理输入延迟，不能据此宣称帧率提升或显存硬上限。外部 OLE Server、多 GPU/混合 DPI 等设备场景仍按原测试文档单独验收。
- 公开工具命名空间迁到 `Direct2dCad.Application.Tools` / `.Platform`，渲染宿主改由 `ICadRenderSessionFactory` 注入。仓库内调用方和依赖锁已更新；仓库外若存在直接使用旧类型的代码，需要同步迁移。
- 本次完成本地实现、文档和验证；未提交、推送、运行云端 CI 或发布安装包。
