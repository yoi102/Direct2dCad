## 标注

Ribbon 的“标注”页提供水平、垂直、对齐、半径、直径、角度和引线。预选一条线再选线性/对齐工具，或预选圆/圆弧再选半径/直径工具，即可移动预览并左键放置。也可以在画布指定基准点；角度依次指定顶点和两条射线上的点。每个已确认的基准点显示小圆点，缩放时保持屏幕大小，鼠标离开画布后仍保留；放置、完成、取消或切换工具时清除。标记只是临时覆盖层，不增加图纸实体或撤销记录。

标注使用画布上的小数字框，右侧“图纸恢复”不再显示步骤文字、坐标框及完成/取消按钮，左侧保留标注参数。画布直接键入数字，Tab 切换 X/Y 或长度/角度字段，Enter 接受当前点；已输入的数值固定并实时更新预览。不显示大面板或常驻操作提示，完整步骤收在状态栏当前模式的悬停提示中。半径/直径标注选择源圆时不显示数值框，选择后再提供放置坐标。Terminal 仍支持绝对、相对和极坐标。连续模式记住参数；画布 Enter / Terminal DONE 完成，Esc 清理未提交点，保留已经放置的尺寸。操作细节见[动态输入](DRAWING-AND-EDITING.md#精确输入和捕捉)。

属性工具箱统一垂直滚动，标注内容不会因面板变矮而被裁切。样式、单位、精度和替代文字位于上方；默认展开的“文字与箭头”提供内置矢量字体、开放/闭合箭头或斜线、纸面字号及箭头大小。“比例与尺寸线”提供注释比例、标注线宽和延伸线参数。绘制时修改设置会立即更新预览，并用于新标注；选中已有尺寸后，属性修改实时更新到图上，无需点击“应用”或离开输入框。一个输入框中的连续输入默认作为一次撤销操作，切换预设样式也只需撤销一次；不同字段分别撤销。非法值不会写入图纸，锁定或只读标注的参数不可修改。底部只保留重新关联和解除关联的两个图标，悬停显示文字。替代文字前显示 `*`，避免把它误认为测量值。尺寸只有一个可移动的位置 grip；沿用点击 grip、移动预览、再次左键提交的习惯。

默认 ISO，另有 Fine 和 Large。字号和箭头以纸面毫米输入；在活动布局模型视口中开始标注会取视口比例的倒数，例如 `1:100` 使用注释比例 100，在纸空间使用 1。已创建标注不会在以后修改视口比例时自动重写；需要按目标视口修改注释比例。同一模型尺寸在不同比例视口中显示时，纸面大小可能不同。

关联只使用同一 owner 中可证明的直接引用：直线端点、圆/圆弧中心和固定角度点、圆弧端点、拓扑点数未变化的多段线顶点。重合的多个候选不会猜目标；嵌套块投影、拆分和连接不会按最近位置重新绑定。失效时保留完整最后接受的尺寸，显示 `!` 和叉号，属性提供“重新关联”和“解除”。复制时只关联同一次复制出的源对象；单独复制尺寸则解除。旋转、缩放、镜像明确解除关联，撤销恢复引用；平移有关联尺寸时只移动标注位置。

尺寸是独立实体，接入选择、命中、渲染、打印、grip、复制、历史和版本化存储。尺寸字体为项目内置笔画字体，不代表任意 TrueType/SHX 字体兼容。旧版遇到新尺寸 section 会进入兼容只读保护。完整参数约束、公差/形位符号和自动注释比例集合属于后续范围。

Terminal 别名：`DIM`/`DIMLINEAR`、`DIMVERTICAL`、`DIMALIGNED`、`DIMRADIUS`、`DIMDIAMETER`、`DIMANGULAR`、`LEADER`。公共 `add_dimension` 与鼠标使用同一实体和命令，支持创建时指定字体、箭头和详细样式；`set_dimension` 编辑已有标注并保留关联，`detach_dimension` 明确解除关联，均支持撤销。查询返回测量、显示文字、样式和引用，示例见[命令行与 AI](COMMANDS-AND-AI.md)。

## 工程模板

文件页的“新建”下拉菜单提供空白图纸、A4 · mm · 1:1、A3 · mm · 1:100 和 Letter · in · 1:1。模板设置真实纸张尺寸、图形显示单位和模型视口比例；内部几何始终为毫米。模板是新图纸入口，不修改当前图纸。

“打开文件”下拉菜单提供原生图纸与“打开 DXF”；“保存”下拉菜单提供保存、另存为和另存压缩副本。三个菜单均可点击按钮或按空格展开，也可用下方向键展开后移动选择；Enter 执行，Esc 关闭。选中操作后菜单自动收起。

左上角“文件”菜单也提供新建、工程模板、打开文件、打开 DXF、保存、另存为、另存压缩副本、导出 DXF 和打印。工程模板收在子菜单中，其余按操作分组并使用图标；欢迎页隐藏保存、导出和打印入口。

## 比例打印

模型空间和布局均可打印。预览选择“实际尺寸 / 适合纸张 / 自定义”；只有自定义时显示百分比，DPI 放在详情。模型另选全图或当前视图范围。实际尺寸不会因超出可打印区域自动改为 fit。预览显示红色可打印边界、范围外淡红区域及裁切提示；提交按可打印区域裁切。

模型视口比例与整纸缩放独立：视口 `1:100`、整纸 `100%` 时，10000 mm 的模型线在纸面为 100 mm。预览和提交共用驱动校验后的 PrintTicket 与比例结果；更改打印机或设置会禁用提交，待最新预览完成再开放。打印完成表示驱动写入完成，不代表纸张已物理输出。

本机已运行 Microsoft Print to PDF 的票据/预览校验，未提交打印作业；100 mm 实际 PDF 文件和纸面测量仍需现场验收。

## DXF 支持矩阵

导出为 ASCII DXF R2004 (`AC1018`)，真彩色和 Unicode 转义；导入接受 R12、R2000、R2004 至 R2018 的声明版本中的下列子集。ASCII 指组码文本文件；支持严格 UTF-8 与 `\U+XXXX`，不支持二进制 DXF 和所有历史 ANSI 代码页。

| 内容 | 当前策略 |
| --- | --- |
| LINE / CIRCLE / ARC | 平面解析几何；负扫角导出为等价 CCW 圆弧 |
| LWPOLYLINE | 开闭多段线、圆弧 bulge；非零宽度另报未支持 |
| TEXT | 基本插入点、字号、旋转、Unicode；特殊对齐/变形拒绝并汇总，字体差异汇总 |
| LAYER | 名称、真彩色/基础 ACI、线宽、可见/冻结/锁定；BYLAYER 常用虚线解析到实体 |
| BLOCK / INSERT | 定义、基点、嵌套、旋转和非均匀比例；循环/深度超限拒绝，阵列 INSERT 单独汇总 |
| 尺寸 | 导出为笔画，明确报告关联和尺寸语义丢失 |
| 面域（CadRegion） | 暂不支持 DXF 面域转换；导出先汇总这类实体，未授权有损导出时不写文件，明确确认后才可省略 |
| 特殊内容 | 样条、椭圆、Hatch、OLE、光栅、纸空间等汇总；实体锁、填充、端帽/连接、自定义线型等损失先确认 |

实体隐藏状态保留。ACI 1–7 保留；其余 ACI 替代为白色并汇总，不宣称完整调色板支持。没有可靠单位时集中选择一次；不猜单位。最大 64 MiB、300 万组码、50 万记录和 32 层块深度。记录和结构非法时拒绝整次导入。

“打开 DXF”生成新未保存图纸。“导出 DXF”保留 `.d2cad` 源路径，在写入前集中确认损失；覆盖需确认当前文件版本，取消和失败清除临时文件。Terminal/AI 可调用 `open_dxf` 和 `export_dxf`；后者缺少损失授权时只返回摘要、不写文件，已有目标需要 `overwrite=true`。

固定外部 ezdxf 样图、来源许可和 SHA256 位于 [samples/dxf](samples/dxf/ezdxf-source.json)。独立 ezdxf 1.4.3 校验了导出文件结构、100 mm 线、隐藏状态、中文、图层颜色、块和非均匀插入，并比对外部样图的线/圆弧几何。详见 [M4–M6 证据](validation/2026-10-03/m4-m6/README.md)。DWG 和完整 DXF 对象覆盖另列阶段。
